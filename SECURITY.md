# Segurança / Security

**PT-BR** — Encontrou uma vulnerabilidade? Use o [relato privado de vulnerabilidades do GitHub](https://github.com/EttoreCSenatore/atalaia/security/advisories/new). Não abra issue pública com detalhes. Não envie dados pessoais reais. Respondemos o quanto antes.

**EN** — Found a vulnerability? Use GitHub's [private vulnerability reporting](https://github.com/EttoreCSenatore/atalaia/security/advisories/new). Please do not open a public issue with details, and do not send real personal data.

**Uso responsável / Responsible use** — O Atalaia é uma ferramenta defensiva: use só em redes que você administra ou em que tem autorização por escrito. / Atalaia is a defensive tool: use it only on networks you administer or have written authorization for.

**Versões com correções / Supported versions** — Só a **versão mais recente** recebe correções de segurança (o projeto é novo e mantido por uma pessoa). Atualize antes de relatar. / Only the **latest release** receives security fixes (the project is new and maintained by one person). Please update before reporting.

**O que esperar / What to expect** — Confirmação em poucos dias e, se for procedente, correção e aviso na release (com crédito, se você quiser). Não há programa de recompensas. / An acknowledgement within a few days and, if valid, a fix and a note in the release (with credit, if you wish). There is no bug bounty.

**Escopo / Scope** — O código deste repositório, o app web, a API, os pacotes e a imagem Docker. A revisão de segurança feita até aqui foi do próprio projeto e não substitui um teste de invasão independente: veja a [página de segurança](https://ettorecsenatore.github.io/atalaia/docs/tecnico/seguranca-e-privacidade). / The code in this repository, the web app, the API, the packages and the Docker image. The security review done so far was by the project itself and does not replace an independent penetration test.

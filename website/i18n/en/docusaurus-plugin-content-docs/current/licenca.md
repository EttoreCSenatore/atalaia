# License

| What | License |
|---|---|
| Code (agent, web app, scripts) | **GNU AGPL-3.0-or-later** (`LICENSE` file) |
| Documentation and site images | **CC BY-SA 4.0** (`LICENSE-DOCS.md` file) |

The AGPL ensures that anyone hosting a modified version of Atalaia as a service must also release that version's source code. That is why the web app shows, on every page and in Settings, a **Source code** link to the repository (at the tag of the running version). **If you modify Atalaia and offer it to other people, change that link to point to your code.**

The "Atalaia" name and logo are not covered by the licenses above. The [NOTICE](https://github.com/EttoreCSenatore/atalaia/blob/main/NOTICE) file says how the name may be used and records that Atalaia is an independent project, **not affiliated with Fing Limited**, using none of its trademarks, code or data. To contribute, see [CONTRIBUTING](https://github.com/EttoreCSenatore/atalaia/blob/main/CONTRIBUTING.md) and the [Code of Conduct](https://github.com/EttoreCSenatore/atalaia/blob/main/CODE_OF_CONDUCT.md).

## Third-party data

Atalaia uses public lists to identify devices (for example, the IEEE MAC vendor list). Each source has its own license, recorded in [Architecture](tecnico/arquitetura.md) before it is included. Proprietary data, such as the fingerprint database of commercial products, is **not** used.

# Licença

| O quê | Licença |
|---|---|
| Código (agente, app web, scripts) | **GNU AGPL-3.0-or-later** (arquivo `LICENSE`) |
| Documentação e imagens do site | **CC BY-SA 4.0** (arquivo `LICENSE-DOCS.md`) |

A AGPL garante que quem hospedar uma versão modificada do Atalaia como serviço também precise abrir o código dessa versão. Por isso o app web traz, em todas as páginas e em Configurações, um link **Código-fonte** para o repositório (na etiqueta da versão em uso). **Se você modificar o Atalaia e oferecê-lo a outras pessoas, troque esse link pelo do seu código.**

O nome e o logotipo "Atalaia" não são cobertos pelas licenças acima.

## Dados de terceiros

O Atalaia usa listas públicas para identificar dispositivos (por exemplo, a lista de fabricantes por MAC do IEEE). Cada fonte tem a sua licença, registrada em [Arquitetura](tecnico/arquitetura.md) antes de ser incluída. Dados proprietários, como a base de impressões digitais de produtos comerciais, **não** são usados.
